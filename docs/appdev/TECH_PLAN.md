## 1. 开发前：代码拆分与复用（重点）

### 1.1 为什么要先拆

- **一个文件管太多事。** `CanvasPageState` 一个类同时负责：手势分发、双指缩放与平移、画纸大小拖把、键盘快捷键、文字工具、移动工具与选区、选区工具条、取色框、☰ 菜单、重命名/删除/新建、工具抽屉、竖屏调色条、撤销条。任何改动都要在 3,556 行里找位置。
- **工具分发是 if/else 链。** `_onDown`/`_onMove`/`_onUp` 三处各有一条「平移 → 文字 → 移动 → 画笔」的分支链。吸管、油漆桶加进来后变成六个分支 × 三处，每加一个工具都要改三处，容易漏。
- **渲染出图放错了地方。** `renderPng`/`renderRgba` 是 `DrawingController` 的静态方法。缩略图、导出、打印要用它，以后回放（GIF 帧）、吸管（读像素）、油漆桶（读整张图）也要用，应该有独立的渲染层。
- **选区操作无法单测。** 复制、删除、变色、旋转等操作被快捷键、选区工具条、菜单三处调用，逻辑写在 State 里，只能用整页的 widget 测试来测。
- **后面的功能都碰同一批代码。** 图层、回放、吸管、油漆桶、画布旋转都要改画板页面。不先拆，`canvas_page.dart` 会涨到 5,000 行以上。

### 1.2 拆分原则

1. **只搬家，不改行为。** 拆分的改动里不带任何功能变化，用户看不出区别。
2. **测试不动。** 313 个测试原样通过，只允许改 import。测试用到的 14 个公开入口（`CanvasPageState.paperKey`、`toolsButtonKey`、`dockedPaletteKey`、`zoomKey`、`selectionBarKey`、`zoomLevel`、`minZoom`、`maxZoom`、`longPressDelay`、`commandKey`、`undoFloatKey`、`toolsListKey`，以及 `state.selected`、`state.selectionFrame`）保留在原处，可以只是转发。
3. **一步一验。** 每拆一块就跑一次 harness：analyze 0 issues、全部测试通过、build web。
4. **逻辑放 controller，界面放 widget。** controller 是纯 Dart，可以单测；widget 只读 controller 的状态、调 controller 的方法。
5. **一个文件一件事。** 单文件尽量不超过 600 行，最多 800 行。

**`CanvasTool` 接口**：每个工具一个类。画板只决定当前用哪个工具，然后把事件转给它。

```dart
abstract class CanvasTool {
  void down(ToolPointer p);
  void move(ToolPointer p);
  void up(ToolPointer p, {required bool cancelled});

  /// 鼠标或手写笔悬停，例如橡皮擦光圈、吸管预览。
  void hover(Offset? at) {}

  /// 画在画纸上方的提示：光圈、放大镜、选框。
  void paintOverlay(Canvas canvas) {}
}
```

## 2. 功能清单

每项按「目标、级别、设计、文件格式、复用、测试、风险」写。

### F1 大画作的流畅度（所有级别）

**目标**：几千笔的画，画新的一笔、用橡皮擦、撤销都不卡。

**先测量，确认确实卡了再改**
- 用 `tool/android_smoke.ps1`（F9）在模拟器上导入高级样例，用 `adb input swipe` 画 20 笔、擦 10 下，读 `dumpsys gfxinfo` 里的卡顿帧比例和 90/99 分位帧时间。
- 在单测里给 `paintStrokes` 计时，只用来比较改动前后的相对值。

**设计**
- **`LayerCache`**：把已完成的笔画存成一张位图（`ui.Image`），分辨率 = 画纸大小 × 屏幕像素比，最长边不超过 4096。
  - 新增一笔：旧图加这一笔，生成新图（`toImageSync`，只画这一笔）。
  - 撤销、删除、移动、改色这类非追加的修改：后台整张重建，重建完成前继续显示旧图。
  - 正在用橡皮擦时：把旧图和橡皮擦这一笔（`dstOut`）放进同一个图层里画，不再每移动一下就重画全部笔画。
  - 放大到超过位图分辨率时：改为按矢量画，只画与可见区域相交的笔画；停止缩放后按新分辨率重建。
- 晕染笔要取「下面的画」时，优先从 `LayerCache` 截取对应区域，不再把下面的笔画重画一遍。
- **文件大小（可选）**：先测 2.6 MB 样例的加载耗时，超过 300 ms 才考虑压缩，而且只压缩 App 内部的存储，`.jypaint` 格式不变。

**复用**：建在渲染层之上；回放（F4）和图层（F6）直接使用 `LayerCache`。

**测试**：缓存画出的结果与直接绘制逐像素一致，覆盖追加、撤销、橡皮擦、晕染、换画纸颜色；缓存何时失效有单测。

**风险**：内存占用（4096² 一张约 64 MB）；`toImageSync` 在网页版上的表现要实测。

### F2 吸管取色（中级起）

- **工具**：新工具 `BrushType.picker`（工具栏里叫「吸管」）。按住拖动时出现放大镜，显示 9×9 像素的放大图和中心点颜色。松手后取色：设为当前颜色，加进最近颜色，并自动切回上一个笔刷。
- **电脑**：按住 Alt 点击是临时吸管，快捷键 I。
- **取到的颜色**：取的是「看到的颜色」，包括混合、纹理、半透明叠加，以及在画纸颜色上的合成结果。
- **实现**：`PixelSampler.sample(9×9 区域)`，优先读 `LayerCache`；没有缓存时临时渲染这一小块。
- **文件格式**：无变化，吸管不产生笔画。
- **测试**：纯色、半透明叠加、画纸色；放大镜不出屏幕；用完切回上一个笔刷；按级别隐藏；中英文标签。

### F3 油漆桶（初级起）

- **工具**：新工具 `BrushType.bucket`。点一块区域，用当前颜色填满；中级起可以用渐变填。
- **算法**
  1. `PixelSampler` 把整张画纸渲染成 RGBA，最长边不超过 2048。
  2. 从点按处做扫描线洪水填充，颜色容差默认 32。
  3. 补缝隙：先把边界膨胀 N 像素再填，填完再把结果膨胀回来，这样没完全封口的线也能填。N 默认 2；中级起工具面板里有「缝隙」滑块，范围 0–6。
  4. 结果再向外扩 1 像素，塞到线条的抗锯齿边下面，避免出现白边。
  5. 轮廓追踪（marching squares）加简化（Douglas–Peucker，0.75 px），得到外轮廓和洞的轮廓。
  6. 生成一个普通的「自由形状」笔画（`fill: true`），放在最上面。
- **文件格式**：`Stroke` 新增可选字段 `holes`（洞的轮廓）。旧版本打开时洞也会被填上，盖住被围起来的部分，这可以接受，会写进更新说明。
- **复用**：结果是普通笔画，所以移动、旋转、改色、渐变、纹理、撤销、保存都是现成的；`PixelSampler` 与吸管共用。
- **性能**：在 isolate（`compute`）里做 2048² 的填充。网页版没有 isolate，所以限制在 1024²，并显示「正在填色…」。
- **测试**：封闭的圆内填色；有 2 px 缺口的圆不漏；带洞的形状（甜甜圈）；空白画纸整张填满；同一块再填一次（换色）；撤销一步；保存后重新打开一致。
- **风险**：复杂区域（喷枪点、纹理）的轮廓点很多，要设点数上限并简化；容差在纹理笔画上可能漏填或填不全。

### F4 作画回放和导出 GIF（所有级别）

- **入口**：☰ → 分享 → 「回放作画过程」；我的画作里每张卡片的菜单也有。
- **`ReplayController`**
  - 按笔画顺序播放：自由画笔的笔画按点逐步出现，形状、文字、印章一次出现。
  - 总时长按笔画数自动调整，在 10–40 秒之间；倍速 0.5×、1×、2×、4×；进度条可以拖动。
- **渲染**：已完成的笔画累加进 `LayerCache`（追加接口）；正在出现的这一笔用 `copyWith(points: 前 k 个点)` 画。往回拖时，从最近的关键帧（每 200 笔存一张小图）重建。
- **导出 GIF**：最长边 480 px、12 fps、最多 15 秒，用已有的 `image` 包在 isolate 里编码并显示进度，走已有的分享和下载流程（`share_actions`）。
- **文件格式**：无变化。
- **测试**：时间到进度的换算；从关键帧重建与顺序播放逐像素一致；GIF 的文件头和帧数；取消导出。
- **风险**：网页版上 GIF 编码在主线程，很慢，所以网页版降到 320 px、8 fps。

### F5 备份提醒（所有级别，主要为网页版）

- **记录**：每个小画家记一个 `lastBackupAt`，「导出全部」就算一次备份。
- **提醒条**：在我的画作顶部显示。条件是有新画或改过的画，并且距上次备份已有 14 天以上，或者从未备份且已有 3 幅以上。
  - 文字：「上次备份：X 天前」。
  - 「一键备份」：把这个小画家的全部画作导出成 zip，复用现有的导出。
  - 「以后再说」：7 天后再提醒。
- **网页版**：设置 → 关于里显示浏览器是否保证不清除数据（`navigator.storage.persisted`）；没有保证时，提醒间隔缩短为 7 天。
- **设置**：设置里可以关闭提醒。
- **测试**：什么时候显示、什么时候不显示；一键备份后提醒消失；「以后再说」；切换小画家；中英文。

### F6 图层（高级）

- **数据**
  - `PaintingLayer {id, name, visible, opacity, locked}`。
  - `Stroke` 新增可选字段 `layer`，缺省就是底层。
  - `DrawingController` 增加 `layers`（从下到上）和 `activeLayer`。
  - 笔画仍然存在一个列表里，层内顺序不变，渲染时按图层分组。
- **渲染**：每个图层单独一个 `saveLayer`（带不透明度），所以橡皮擦只擦当前图层；晕染笔仍然能看到它下面所有可见的内容，与现在一致。每个图层一个 `LayerCache`（F1），改上层时不重画下层。
- **编辑**
  - 画笔、油漆桶、文字都画在当前图层。
  - 选择、框选、命中只针对当前图层，锁定或隐藏的图层不能选。
  - 撤销快照包含图层列表。
- **界面**：工具抽屉里的「图层」按钮，只在高级显示，点开是图层面板。
  - 每层显示缩略图，可以显示或隐藏、锁定、调不透明度、重命名。
  - 可以新建、删除（图层里有内容时要确认）、拖动排序、向下合并。
  - 最多 10 层。
- **文件格式**：画作新增可选字段 `layers`，笔画新增可选字段 `layer`，保存时笔画按图层顺序排好。旧版本打开时，所有笔画按正确的上下顺序平铺显示，但丢失隐藏、不透明度和锁定。
- **降低级别后**：已有的图层照常显示，面板隐藏，新画的内容画在当前图层。
- **测试**：模型（增、删、排序、合并）；渲染（不透明度、隐藏、橡皮擦只擦本层）；保存与读取；读取旧格式；撤销；选区只限本层；无障碍。
- **风险**：改动最大的一项，涉及渲染、选区、存档和界面，必须在代码拆分（R）和 F1 之后做。

### F7 照片底图、临摹和涂色本（照片：中级起；涂色本：所有级别）

- **照片**
  - 入口：☰ → 画纸 → 「导入照片」，用 `file_selector`，所有平台都能用。
  - 存储：图片缩到最长边 2048、JPEG 85%，存在画作的 `assets` 表里，图片笔画引用它。
  - 编辑：可以移动、缩放、旋转，复用 `StrokeTransform` 和选区。
- **临摹模式**：有图层（F6）时，照片放进单独的底层「照片」，不透明度 40% 并锁定；导出时可以选择不包含照片层。
- **涂色本**
  - 内置 8–12 张线稿，用 `tool/samples` 的作画脚本生成，和样例画是同一套工具。
  - 新建画作时可选「空白」或「涂色本」。
  - 线稿在锁定的最上层，孩子画在它下面的图层。油漆桶按所有可见图层判断边界，所以能填满线稿围起来的区域。
- **文件格式**：画作新增可选字段 `assets`（id → base64 JPEG）。旧版本打开时，图片笔画显示不出来，当作空笔画。
- **测试**：导入、缩放后保存再读取一致；超大图片被缩小；导出时包含或不包含照片层；用涂色本新建画作并填色。
- **风险**：画作文件变大，每张照片 0.3–0.8 MB。

### F8 画布旋转（中级起）

- **操作**
  - 双指旋转，可以和缩放同时进行；角度在 0°、90°、180°、270° 附近 7° 以内时自动吸附。
  - 缩放标签显示成「150% · 30°」，点一下同时复位缩放和角度。
  - 电脑上 R 和 Shift+R 每次转 15°。
- **要修正的地方**
  - `zoomLevel` 改为取 x 轴基向量的长度 √(m00² + m10²)，否则旋转后会读错缩放值（规则 23 的延伸）。
  - 旋转时隐藏画纸边缘的拖把，只在 0° 时显示。
  - 检查选区工具条的定位。
- **初级不开启**，避免孩子误转。
- **测试**：旋转手势、吸附、复位；旋转后画的线仍落在手指下；缩放值正确。

### F1 小结（2026-10-27）

- **测量工具**：`tool/bench/drawing_bench.dart` 是同一套测量流程：画 8 笔、擦 4 下、撤销 4 次，各测一遍「不用缓存」和「用缓存」。有两个入口：
  - Chrome：`tool/bench/web_bench.ps1`。它构建测速网页，用本地 Dart 服务器（`tool/bench/serve.dart`）提供，再用临时配置的 Chrome 打开。
  - 设备：`integration_test/draw_perf_test.dart`。
  - 本机的 Android 模拟器跑 3,000 笔的画常常整个崩掉（5 次崩 4 次），所以大画作的测量都在 Chrome 上做。
- **结果**：高级样例 3,058 笔，Chrome，每帧「构建 + 渲染」毫秒数：

  | | 不用缓存 | 用缓存 |
  |---|---|---|
  | 画新的一笔 | 15 + 178 | 5.5 + 1.4 |
  | 橡皮擦 | 291 + 353 | 5.4 + 1.1 |
  | 撤销 | 197 + 294 | 6.1 + 1.0 |

  中级样例 1,101 笔，在软件渲染的模拟器上：画新的一笔每帧渲染从 701 毫秒降到 129 毫秒，测量期间的帧数从 12 帧增加到 73 帧。
- **做法**：`render/layer_cache.dart` 的 `StrokeLayerCache` 把已完成的笔画层存成一张图，不含画纸。
  - 新加的笔画直接叠上去；用橡皮擦时只画这张图和橡皮擦这一笔。
  - 最近几步的图（最多 8 张，合计约 64 MB 以内）留着给撤销和重做用。
  - 只有移动、改色这类修改才整张重建。
  - 正在用的晕染笔也直接从这张图取「下面的画」。
  - 图的分辨率按屏幕实际需要，缩放到 1、2、4、8 倍时分档重建；超过约 1,600 万像素时，退回直接画矢量。
- **验证**：`test/layer_cache_test.dart` 有 8 个测试。缓存画出的结果与逐笔绘制逐像素对比，差异不超过 2 级色阶，覆盖正片叠底、荧光笔、橡皮擦和晕染笔。也测了什么时候该重建、什么时候不该。
- **还没做的**：
  - 第一次打开大画作仍要整张画一遍。
  - 放大到上限以上会退回矢量绘制，以后可以考虑分块缓存。
  - 自动保存的缩略图仍然逐笔绘制，但只有 360 像素宽，测量中最慢的一帧约 39 毫秒。
  - `.jypaint` 文件大小经测量不是瓶颈，没有改。

### F2、F3 小结（2026-10-28）

- **F2 吸管**
  - `canvas/tools/picker_tool.dart` 是吸管工具，`canvas/picker_loupe.dart` 是放大镜，`render/pixel_sampler.dart` 的 `PaperSampler` 负责读颜色。有缓存图时只读手指周围 9×9 像素。
  - 松手时先切回原来的笔刷，再设颜色。原因：App 的规则是「设置颜色时，如果当前工具不用颜色，就切回钢笔」，顺序反了会被切成钢笔。
- **F3 油漆桶**
  - `render/flood_fill.dart` 负责算区域，不依赖界面：容差 32，先补缝隙再填，然后退回到真实边界，再向线下多铺 1 像素。轮廓沿像素边追踪，按奇偶规则填充；6 像素²以下的小洞直接填掉；轮廓用 Douglas–Peucker 简化。
  - 填色结果是普通的自由形状笔画，另带一个精确区域 `Stroke.area`。旧版本打开时，按外框画一个圆角的填充，没有洞。
  - App 里填色在后台线程算（`compute`）。网页版没有后台线程，工作分辨率改为最长边 1,024 像素：3,058 笔的画上一次填色 96 毫秒。
  - 「补缝隙」滑块中级起显示（0–6，默认 2）。
- **版本**：R、F9、F1、F2、F3 一起作为 4.1.0 发布。

### F4、F5 小结（2026-10-28，4.2.0）

- **F4 回放**
  - `drawing/replay/`：`ReplayTimeline` 是时间轴：自由画笔按点数计时，每笔最多 1.5 秒；形状、文字和填色一次出现；总时长最多 40 秒，超出就加速。
  - `paintReplayFrame` 画出某一时刻的画面，复用 `StrokeLayerCache`，所以回放大画作也流畅。正在出现的是橡皮擦或晕染笔时，和作画时一样处理。
  - `Stroke.partial` 生成「画到一半」的笔画。
  - GIF：`replayGif`，最长边 400 像素、每秒 10 帧、最多 10 秒，网页版 320 像素、每秒 8 帧。帧在主线程画好，再交给后台线程编码：image 包，八叉树取色，不抖动，最后一帧停 2 秒。可以中途取消。文件交给现有的 `shareExportedFile`。
  - 入口：☰ → 分享 → 「回放作画过程」，以及「我的画作」卡片菜单。
- **F5 备份提醒**
  - `gallery/backup_reminder.dart`：`BackupReminder.due` 判断何时提醒，`BackupBanner` 是提醒条。
  - 规则：
    - 从未备份过：画满 3 幅、最早的一幅超过 14 天时提醒。浏览器没有承诺保存数据（`storageAtRisk`）时改为 7 天。
    - 备份过：之后有改动，且距上次备份超过 14 天（同上，7 天）时提醒。
    - 「以后再说」推迟 7 天。
  - 「一键备份」导出全部画作。手动勾选导出了全部画作，也算一次备份。
  - 每个小画家分开记录。设置里可以关掉。

### F6 小结（2026-10-28，5.0.0）

- **数据**
  - `drawing/layers.dart` 的 `PaintingLayer`：id、名称、显示、不透明度、锁定。
  - `Stroke.layer` 为 null 表示底层，所以旧画作完全不变。
  - `PaintingDoc.layers` 只在多于一层时保存。
  - `DrawingController` 让笔画列表始终按图层分组排列，新笔画插到所属图层的末尾。图层的增、删、排序、合并、显示/隐藏、锁定、不透明度和重命名都能撤销。
- **渲染**
  - `paintStrokes(..., layers:)`：每个显示的图层单独一张，按图层不透明度合成。橡皮擦和晕染笔只作用于本层。
  - `LayeredCache` 每层一个 `StrokeLayerCache`。
  - 导出、打印、缩略图、回放和 GIF 都按图层合成。
  - 吸管和油漆桶读的是所有可见图层合成后的样子，填色放进当前图层。
- **编辑**
  - 新笔画、文字和填色都画在当前图层，粘贴也进当前图层。
  - 选择、框选、全选只针对当前图层，锁定或隐藏的图层不能选。
  - 当前图层隐藏或锁定时，画笔、文字、油漆桶都不落笔，并提示原因；这一下触摸也不会拖动画纸。
- **界面（高级）**：工具抽屉最上面一行「图层」，点开图层面板：
  - 新建图层，最多 10 层。
  - 拖动排序；每层有缩略图（取自该层的缓存图）、显示/隐藏、锁定，以及菜单里的重命名、向下合并、删除（有内容时先确认）。
  - 当前图层的不透明度滑块，拖一次只算一步撤销。
- **旧版本打开**：所有笔画按上下顺序平铺显示；隐藏、不透明度、锁定不起作用；上层的橡皮擦会擦到下层。
- **测试**：`test/layers_test.dart` 有 10 个测试。Chrome 测速与 4.1.0 相同。
